# Chess standalone sample3
Offline Android APK of chess/3/sample3.html. Original HTML and icon are bundled unchanged.
Label Chess; package io.github.ae6820dc.chesssample3. Independent of Chess Studio 3 and Credit Chess.
Original blue appearance, legal two-player moves, drag input, New Game, Flip Board, checkmate and game counter are preserved.
No native toolbar; no network permission. Application pause saves the current game.
Build: bash build-sdk.sh with JDK and Android SDK platform/build-tools 36.
Distribution: apk/Chess.apk.
